## 0. Job of the product

Work Engineering is the specification layer between enterprise intent and execution.

It does **not** run the work. People, agents, RPA, and BPO consume the spec.

**One sentence:** We sit three altitudes on one journey, bind only what a helper would need a permit for, and refuse what we cannot defend.

**The quality stack (this is the ambition)**

```
High-quality sitting
        ↓
High-quality understanding of their process
        ↓
High-quality genome (objects changing condition)
        ↓
High-quality work graph (journey you can read)
        ↓
Hours we will defend, stops that do not lift, spec that denies without a file
```

If discovery is a form, the genome is a spreadsheet and the graph is a poster. That is today’s gap. The law is ahead of the room.

### 3.2 Three rooms (same chrome)

Every room: one question, transcript as source of truth, inspector on the right (what this sentence may become). Type on the demo path. Voice offstage until certified.

**Room A — Function leader (CHRO)**  
Altitude: the year and the last break. Never offer steps. Never 18 fields.

1. “Last time an offer got messy after we said yes — what broke first?”  
2. Play back. “We heard: … Wrong?”  
3. “Who is allowed to let that through anyway?”  
4. “If we only fix one thing this quarter on this desk, is it that stop — or something else?”  
5. In / out. Pack stops as checkboxes from `hard_anchors.yaml` (they confirm; they do not invent the list).

Lands in: `sitting_answers` on `function_head` → draft `strategy_intent_focus` **only if a literal substring** → Plan this-period row after confirm.

**Room B — Ops (Head of HR operations)**  
Altitude: how this desk is supposed to run.

- Trigger: “A case lands. What does your team open first?”  
- End: “When do you call it done?”  
- Systems: predict-and-validate from **this tenant** (Zwayam / mail / Excel / OneDrive / Zoho already named on Rashmi’s sitting — “still true here, or something else?”).  
- Cover: “When Rashmi is out, what breaks first?”

Empty state: **Ops has not sat** — not a labelled stand-in card that looks complete.

**Room C — Desk (Rashmi)**  
Altitude: Tuesday. Her sheet stays the source. Optional dump → existing `extract-from-story` → “is this you?” → sit-close still quote-gated. If extract refuses, show the refusal. No mock story.

**Playback theatre**  
Three columns from storage. Sample, if shown, is stamped **Sample — not a named sitting**. Disagreement is gold. Do not mash. Strike-through = Correct (existing sit-close shape).

**Sit close**  
Three binding lines only. Confirm only with a quote in their text.

### 3.4 Genome (model, not a warehouse)

A unit is not a SOP line. It is a **change of condition on a business object**.

Objects on this wedge: Offer, Candidate, Employee, Contractor, UAN history.

Each unit must be able to answer, or stay grey:

- Which object?  
- Before → after  
- What starts it / what done means **here**  
- Evidence pointer (file+cell/page or cannot open)  
- Stop (pack or quote)  
- Who must touch  
- How we know (existing five statuses — never 72%)  
- Whose words

Completeness ≠ 18/18 filled. Completeness = a stranger can defend this unit without calling Rashmi.

Offboarding does not live inside the Offer Desk family. Fill-to-100% with whole-HR sample rows is a lie on this wedge.

### 3.5 Work graph (the face of the genome)

Rebuild the **picture**. Do not decorate the four card columns and call it enterprise.

**Canvas:** left → right, Offer → Day-1. One baseline path from Rashmi’s sitting.

**Node:** a piece of work.  
Signals on the node (only these on the canvas):

| Signal | Meaning |
|---|---|
| Name | The piece |
| Colour / glyph | Object (Offer / Employee / …) |
| Two-state chip | Before → after |
| Density / weight | How specified (not a fake case count) |
| Red lock | Pack stop (dual employment) |
| Split halo | CHRO vs desk disagreement |
| Grey | Not sat / not defendable |

**Edge:** handoff or wait. Label with what moves (packet, UAN, letter).

**Click:** inspector — the 18 fields, quote, file+cell, both speakers if they disagree.

**Layers:** CHRO / Ops / Desk on the same journey. Never three mashed boxes.

Hours do **not** live on the graph. 95 / 61.8 live on Plan.

Chart leaf **count** stays 18 for the hire journey. The visual encoding changes. Do not add a 19th leaf to look rich.
